# OnlineYogaTeachers.com Mock-up

This is a standalone static website mock-up for OnlineYogaTeachers.com.

## Files

- `index.html` — the full website in one standalone HTML file with embedded CSS.

## How to view locally

1. Download or clone this folder.
2. Open `index.html` in your browser.

## How to deploy with GitHub Pages

1. Create a new GitHub repository, for example: `onlineyogateachers-site`.
2. Upload `index.html` and this `README.md` file to the repository.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Click **Save**.
6. GitHub will give you a public website link after it finishes publishing.

## Custom domain later

To use `onlineyogateachers.com` or `onlineyogateachers.com`, add the domain in GitHub Pages settings and update DNS records at your domain registrar.
